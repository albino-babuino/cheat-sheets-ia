# Datos — 07.c ejemplos no supervisados

Los CSV **no se versionan** en git. Descárgalos desde la carpeta padre:

```bash
cd ..
chmod +x download_datasets.sh
./download_datasets.sh
```

| Archivo | Origen |
|---------|--------|
| `iris.csv` | UCI Iris |
| `wine_quality_red.csv` | UCI Wine Quality (separador `;`) |

También puedes reutilizar los mismos archivos de [07.b-ejemplos-supervisados/data/](../07.b-ejemplos-supervisados/data/) copiándolos aquí.
